# BankSystem

Учебная банковская система на Python для изучения ООП.

## Возможности

- Абстрактная модель банковского счёта.
- Пополнение и снятие средств.
- Статусы: активный, замороженный, закрытый.
- Валюты: RUB, USD, EUR, KZT, CNY.
- Проверка входных данных и обработка ошибок.
- Денежные расчёты с использованием `Decimal`.

## Требования

- Python 3.10 или новее.
- Сторонние библиотеки не требуются.

## Быстрый запуск

Команды для PowerShell. Выполняйте их из папки проекта.

### Первый запуск

Создайте виртуальное окружение:

```powershell
py -m venv .venv
```

Запустите демонстрацию:

```powershell
.\.venv\Scripts\python.exe -B demo.py
```

Если окружение `.venv` уже существует, создавать его повторно не нужно.
Активация окружения для этой команды не требуется.

### Что показывает демонстрация

1. Создание активного счёта с балансом 1000 RUB.
2. Пополнение на 500 RUB.
3. Снятие 200 RUB — итоговый баланс 1300 RUB.
4. Создание замороженного счёта с балансом 2000 RUB.
5. Отклонение пополнения и снятия для замороженного счёта.

## Ограничения

Данные хранятся в памяти и не сохраняются между запусками.
Проверка уникальности номеров среди всех счетов пока не реализована.
Проект является учебной моделью.
